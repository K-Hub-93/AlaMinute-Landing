# AlM-Landing

Statische Landing-Page für À la Minute, live unter [landing.on.alaminute.app](https://landing.on.alaminute.app).

## Deploy

- Auto-Deploy via Vercel bei jedem Push auf `main`
- Domain: `landing.on.alaminute.app` (CNAME → Vercel)

## Lokal anschauen

`index.html` einfach im Browser öffnen (Doppelklick) — keine Build-Schritte nötig.

## Inhalt ändern

Direkt `index.html` editieren, committen, pushen — Vercel deployed automatisch.
